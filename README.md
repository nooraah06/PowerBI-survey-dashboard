# Power BI Sales Analysis Dashboard (Guided Project)

This project was completed as part of a guided Power BI learning project. The goal was to understand how to clean data, build dashboards, and create interactive visualizations.

## Tools Used
- Power BI
- Excel
- Data Visualization

## Dashboard Features
- Sales trend analysis
- Product category performance
- KPI indicators
- Interactive filters

## Learning Outcome
Through this project I learned:
- Data cleaning
- Data modeling
- Dashboard design
- Business insights visualization
